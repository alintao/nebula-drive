# NebulaDrive 星云网盘 — 功能规划（对标 ZFile）

> 对标项目：[zfile-dev/zfile](https://github.com/zfile-dev/zfile) —— 免费开源的在线云盘/网盘/对象存储聚合系统。
> NebulaDrive 完整覆盖 ZFile 全部核心功能，并新增 **文件同步引擎、桌面客户端、移动端 App** 三大 ZFile 不具备的能力域。

## 2. 技术选型

| 模块 | 技术 | 理由 |
|------|------|------|
| 服务端 | Node.js 20+ / Fastify / TypeScript / better-sqlite3 | 高性能、零配置 DB、与前端同构 |
| Web 端 | Vue 3 / Vite / Element Plus / Pinia / Vue Router | 与 ZFile 前端同生态，组件丰富 |
| 同步引擎 | Node.js / chokidar / better-sqlite3 / SHA-1 | 跨平台、可被桌面端 sidecar 复用 |
| 桌面端 | Tauri v2（Rust）+ sidecar | 体积小、内存低、原生托盘 |
| 移动端 | uni-app（Vue 3） | 一套代码 → Android/iOS/H5/小程序 |
| 部署 | Docker / docker-compose | 一键部署 |

## 3. 目录结构

```
cloud网盘系统/
├── apps/
│   ├── server/      # Fastify 服务端（API + 存储聚合 + 分享 + 同步通道）
│   ├── web/         # Vue3 Web 管理端 / 文件管理器 / 公开分享页
│   ├── sync/        # 文件同步引擎（CLI + 守护进程）
│   ├── desktop/     # Tauri v2 桌面客户端
│   └── mobile/      # uni-app 移动端
├── docs/            # 功能清单 / 架构 / API / 路线图
├── docker/          # Dockerfile + compose
└── scripts/         # 开发/部署脚本
```
