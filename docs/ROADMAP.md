# NebulaDrive 路线图

## M0（本次交付）
- [x] 服务端：本地/WebDAV/S3/OneDrive/Alist/FTP 六类存储驱动
- [x] 文件管理：浏览/上传(分片+断点)/下载/重命名/移动/复制/删除/批量/回收站/搜索/预览/二维码
- [x] 分享系统：链接/提取码/有效期/下载次数/匿名页/二维码
- [x] 用户系统：JWT/角色/配额/注册开关/登录日志/操作日志
- [x] 系统设置 + 统计面板 + Docker 部署

- [x] 桌面端 Tauri v2 脚手架（托盘 + sidecar 同步）
